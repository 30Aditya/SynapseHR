# SynapseHR - An AI-Powered Human Resource Management System (HRMS) that combines traditional HR operations with intelligent AI-driven recruitment and workforce analytics.

## Features

### Authentication & Security
- JWT Authentication
- Role-Based Access Control (RBAC)
- Secure API Access

### Employee Management
- Add Employees
- Update Employee Information
- Delete Employees
- Employee Directory Management

### Attendance Management
- Attendance Tracking
- Attendance History
- Employee Attendance Monitoring

### Leave Management
- Leave Application
- Leave Approval & Rejection
- Leave Tracking

### Payroll Management
- Salary Management
- Payroll Processing
- Payroll Records

### Performance Management
- Employee Performance Reviews
- Performance Ratings
- Feedback Management

## AI Features

### AI Interview Evaluation

- Candidate Response Analysis

### AI Candidate Ranking

- Employee Risk Assessment

- Workforce Analytics
